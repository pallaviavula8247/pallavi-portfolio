# Pallavi Avula — Reference-Theme React Portfolio

A Vite + React portfolio following the dark, neon-gradient AI/ML reference visual direction, with Pallavi Avula's academic path, experience, certificates, skills and real project screenshots.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Netlify
- Build command: `npm run build`
- Publish directory: `dist`

## Vercel
Import the project; Vercel detects Vite.
